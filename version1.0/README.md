# BTAAHPU-website-demo

安徽工程大学区块链技术协会（AHPU.DAO）官方网站演示项目

## 项目简介

本项目为安徽工程大学区块链技术协会的官方网站，采用现代化的设计风格，展示协会理念与活动信息。

## 技术栈

- **前端框架**: HTML5 + Tailwind CSS
- **字体**: Noto Sans SC + Space Grotesk
- **图标**: FontAwesome 6.4.0
- **特性**: 玻璃拟态效果、动态背景网格、滚动动画

## 功能特点

- 响应式设计，支持深色模式
- 现代化视觉风格
- 合作、交流、创新理念展示

## 部署说明

本项目为静态网站，可直接部署至 GitHub Pages、Vercel、Netlify 等静态托管平台。

`.nojekyll` 文件用于支持 GitHub Pages 部署。

## 注意事项

**仅作测试用，非最终部署版本**
